# WB AI Manager — Telegram AI agent, MVP 1.0

**Работает:** личные чаты и группы (белый список пользователей и групп), администрирование кабинетов, шифрование WB-токенов в SQLite, русскоязычный AI-чат с вызовом реального WB Statistics API, заказы/продажи за период по одному или всем кабинетам, ежедневное уведомление о падении количества заказов по сравнению с предыдущим днём. Все запросы к WB только на чтение.

**Пока НЕ реализовано:** FBO/FBS-остатки, комплекты, закупки, реклама, Excel-выгрузка, гибкая настройка уведомлений и точное совпадение денежных сумм с личным кабинетом. AI прямо сообщает об отсутствии этих функций; не подменяет их вымышленными расчётами. Отчёты WB оперативные и не заменяют финансовую отчётность.

## Установка на сервере (Docker Compose)

1. Создайте нового бота через @BotFather; скопируйте Telegram Bot Token. В @BotFather настройте `/setjoingroups` = Enable. **Privacy Mode можно оставить Enabled**: бот получает команды, упоминания и ответы на свои сообщения.
2. Скопируйте папку проекта на сервер. `cp .env.example .env`. Сгенерируйте ключ шифрования локально: `python3 -c 'from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())'` (если нет cryptography: `python3 -m pip install cryptography`). Вставьте его в `ENCRYPTION_KEY`. При потере ключа уже сохранённые токены нельзя будет расшифровать — сохраните резервную копию безопасно.
3. Укажите `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY` (отдельный платный API-ключ, не подписка ChatGPT), `ADMIN_TELEGRAM_ID` (узнать через `/id` у бота). Задайте доступную вашему API-аккаунту модель в `OPENAI_MODEL`. Сохраните `.env` только на сервере, не отправляйте в чаты/репозиторий.
4. Запустите `docker compose up -d --build`. Логи без вывода секретов: `docker compose logs -f --tail=100`.
5. Администратор пишет боту в **личные сообщения** `/addcab СПб-ТТ`, следующим сообщением отправляет WB API-токен категории **Статистика**; бот удалит сообщение с токеном, проверит чтение заказов и сохранит токен в зашифрованном виде. Чтобы получать продажи, ключ также должен давать доступ к статистике продаж.
6. Администратор добавляет сотрудника: `/adduser 123456789`, ID сотрудник узнаёт командой `/id`. Добавьте бота в группу и **в самой группе** от имени администратора выполните `/allowgroup`. Сотрудники вызывают `@имя_бота Покажи заказы за вчера` или отвечают на сообщение агента.

## Команды

`/help`, `/id`, `/users`, `/adduser ID`, `/deluser ID`, `/groups`, `/allowgroup`, `/denygroup`, `/cabinets`, `/addcab НАЗВАНИЕ`, `/delcab НАЗВАНИЕ`, `/cancel`, `/clear`.

## Безопасность и ограничения

- Групповой отчёт видят **все участники группы**, даже не из белого списка. Добавляйте бота только в приватные группы, где всем участникам разрешено видеть сведения всех кабинетов. Администратор вправе добавлять/удалять группы и API-токены; остальные пользователи могут только читать аналитику.
- В общей группе история контекста **общая для всех** пользователей из белого списка; в личном чате — отдельная. Не отправляйте конфиденциальную информацию в общий чат. Админ не должен писать токены в группу.
- Токены хранятся зашифрованно с Fernet; секрет шифрования в `.env`. Защитите доступ к серверу, папке data и резервным копиям. `/addcab` принимает токен только в личке администратора и удаляет сообщение после получения (Telegram может сохранять копии в уведомлениях/клиентах).
- Только WB API-токены категории «Статистика» достаточны для текущей версии. Для будущих остатков и рекламы понадобятся дополнительные категории API.
- Ограничения WB API: период гарантированного хранения оперативных статистических данных до 90 дней; сумма `finishedPrice` может быть временно нулевой и отличаться от ЛК; заказы и продажи не равны чистой выручке. API может ограничивать частоту запросов; при большом количестве кабинетов и частых запросах возможны задержки/429. При неполном ответе отдаём ошибку вместо выдуманного отчёта.
- Оповещения: ежедневно в `ALERT_HOUR` по `TIMEZONE`; уведомление, если число неотменённых заказов за вчера снизилось относительно позавчера минимум на `ALERT_DROP_PERCENT` процентов. Если за позавчера было 0 заказов, уведомление не формируется. Получатели: личка администратора и все разрешённые группы. Для личной доставки администратор сначала должен открыть чат и нажать Start.
- Одна запущенная копия бота: несколько параллельных реплик с long polling или планировщиком могут дублировать сообщения. SQLite подходит для одного экземпляра; для масштабирования нужна БД и централизованный планировщик.

## Проверка

`python -m compileall -q .` и `python -m pytest -q` (тесты агрегации в папке tests). Живые API-интеграции без реальных секретов и доступа к вашему серверу не проверялись.
